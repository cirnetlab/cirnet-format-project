# CIRNET Project Format Core

[English documentation](docs/en/index.md) · [Tài liệu tiếng Việt](docs/vi/index.md) ·
[Changelog / Lịch sử thay đổi](CHANGELOG.md)

The Rust library reads, saves and exchanges CIRNET engineering projects. The
crate is a **0.2.0 development candidate**. The Project Manifest, Document
Envelope and Package Profile are independent **1.0 candidates**.

Thư viện Rust dùng để đọc, lưu và trao đổi dự án kỹ thuật CIRNET. Crate đang
ở giai đoạn **ứng viên phát triển 0.2.0**. Manifest dự án, envelope tài liệu
và profile gói là các **ứng viên 1.0** có phiên bản độc lập.
