## Unreleased

## v0.2.0 — Development candidate

- Organize the crate around manifest, document, resource graph, serialization,
  integrity, migration, packages, transactions and native storage boundaries.
- Add explicit revision-checked transactions and recovery for interrupted
  local writes. Use domain-owned validation for authored document changes and
  preserve unsupported bytes on unchanged transfers.
- Add typed document capability registration and indexed dependency, reverse
  reference and path queries. Keep resource IDs stable during relocation.
- Separate manifest, envelope and package version constants. Retain 1.0 format
  profiles and byte-preserving Contracts-owned CircuitGraph 1.0–1.2 imports.
- Expose portable package inspection and verification without publication.
  Keep staging and publication in the native adapter.
- Move development and integration guidance to paired English and Vietnamese
  pages. Keep [0.1.0 verification and benchmark evidence](../history/v0.1.0-verification.md).

See the [migration guide](../en/guides/migration.md) for native write API changes
and [verification instructions](../en/contributing/verification.md) for qualification.

## v0.1.0 — Foundation development milestone
